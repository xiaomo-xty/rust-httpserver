# HTTP 服务器项目说明

## 概述
这是一个基于 Rust 实现的 HTTP 服务器，支持部分 HTTP/1.1 协议功能，适用于基础的文件服务和数据交互。默认监听 `127.0.0.1:8080`，静态资源文件存放在 `./public` 目录，动态数据文件存放在 `./data` 目录。

---

## 功能特性
- ​**HTTP/1.1 基础支持**​  
  支持 GET、POST 等基础方法，可处理静态文件请求与简单数据操作。
- ​**默认监听地址**​  
  启动后默认监听 `127.0.0.1:8080`。
- ​**目录结构**​  
  - `./data`: 存储动态数据文件（如 JSON、数据库等）。
  - `./public`: 存放静态资源文件（如 HTML、JS、CSS）。

---

## 运行方式
### 前提条件
- 已安装 [Rust](https://www.rust-lang.org/) 环境（含 Cargo）。

### 启动命令
```bash
# 编译并运行（发布模式）
cargo run --release
```

# 注意事项
- 确保 ./public 和 ./data 目录已存在，否则可能导致运行时错误。
- 当前仅实现部分 HTTP/1.1 协议，复杂请求可能不受支持。
